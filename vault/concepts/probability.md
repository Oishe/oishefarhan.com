# Probability

Probability assigns a measure to uncertain events. For an event $A$,

$$
0 \le P(A) \le 1.
$$

It provides the language used by [[Statistics]] and [[Bayesian Inference]].

## Monte Carlo estimator

For direct comparison with the Quarto-rendered note:

$$
\widehat{\mu}_n = \frac{1}{n}\sum_{i=1}^n X_i.
$$

## Conditional probability

$$
P(A \mid B) = \frac{P(A \cap B)}{P(B)}.
$$
