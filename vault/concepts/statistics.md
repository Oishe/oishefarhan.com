# Statistics

Statistics uses observed data to reason about an underlying process.

It depends on [[Probability Theory|probability theory]] and is applied in [[Monte Carlo Simulation]].

## A tiny table

| Model | Parameters | Use |
| --- | ---: | --- |
| Bernoulli | 1 | Binary outcomes |
| Normal | 2 | Continuous measurements |
