# Attachment Embed

Publication prep copies an attachment only when published content references it.

![[convergence.svg]]

The same file as an ordinary link: [convergence figure](attachments/convergence.svg).

Unreferenced files in `vault/attachments/` never reach the public tree. Referencing one is
what makes it public, so private binaries belong outside that folder.
